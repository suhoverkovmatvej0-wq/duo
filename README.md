# DUO CHAOS — выживание вдвоём (Forge 1.16.5, лёгкая версия)

## Сборка
1. Скачай Forge MDK 1.16.5-36.2.39 (files.minecraftforge.net) и распакуй.
2. Замени в MDK папку `src` на `src` из этого архива, а `build.gradle` — на файл из архива.
3. Нужна Java 8. Выполни `gradlew build` -> `build/libs/duo_chaos-1.0.0.jar` в папку `mods`.
   Тест из среды разработки: `gradlew runClient`.
4. ВАЖНО: Царство Хаоса (измерение) создаётся только в НОВОМ мире.

## Что есть
События (каждые 10–15 мин, только Верхний мир): нашествие куриц, алмазный дождь, перевёрнутый мир, слизневая эпидемия, охота за сокровищами.
Мобы: Воришка, Утка-убийца, Король Хаоса (4 фазы + разделение при 10%).
Предметы: Радужный меч, Посох телепортации, Слизневая бомба, Крюк-кошка, Молот грома, Молот Короля, Корона Хаоса, Печать Хаоса.
«Друг или враг?»: раз в 3 дня тайное задание одному игроку.

## Команды (нужны права оператора)
/duochaos event <chickens|diamonds|gravity|slimes|treasure|random|stop>
/duochaos mission   /duochaos thief   /duochaos duck
Босс: скрафти Печать Хаоса (4 обсидиана, 4 жемчуга Края, алмаз) и используй (в творчестве — в любой день, иначе с 25-го дня).

## Для слабых ПК
Нет новых блоков и генерации мира, моделей мобов — только ванильные; все события ограничены по числу существ.
Настройки: интервал событий — `ChaosEvents.newDelay()`, день босса — `DuoChaosMod.SIGIL_MIN_DAY`.
